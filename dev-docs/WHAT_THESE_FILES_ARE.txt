WHAT THIS FOLDER IS
===================

Notes for whoever maintains the pipeline. Not for the public, and not for
readers of the results -- these explain how the machinery works and why it was
built the way it is.

The results themselves are elsewhere: data/analysis/ for the figures and tables,
docs/ for the public website. Each of those folders has its own note.

If you are running the pipeline and nothing has gone wrong, you do not need this
folder at all -- the README covers a whole season, start to finish.


IF SOMETHING NEEDS YOU
======================

  PIPELINE_GUIDE.md    The main guide, in three parts: running a season,
                       answering the questions the pipeline asks, and how the
                       code is put together.

  MANUAL_INPUTS.md     Every file a person hand-edits, and what it is for. The
                       counterpart to everything named _generated, which the
                       pipeline rewrites and you never touch.

  SPECIMEN_CHANGELOG.md  Version history of the specimen spreadsheet, and how to
                       bump it when you add specimens.


GETTING AND SHARING THE DATA
============================

  DATA_ACCESS.md       What is in this repository, what is kept out, how to get
                       the data that is kept out, and what to strip before
                       handing it to anyone.


WHAT THE NUMBERS MEAN
=====================

  DATA_ANALYSIS.md     Every analysis: a flow chart of what runs, where each
                       figure and table lands, and the scope, parameters and
                       statistical test behind each one.

  LIMITATIONS.md       What the pipeline knowingly trades away, grouped by the
                       stage that causes it. Read it before quoting a number in
                       something permanent.


HOW THE CODE IS PUT TOGETHER
============================

  WEBSITE_GUIDE.md     How a page reaches the public site, the layout every page
                       follows, and how to publish from your own account.

  SPATIAL_MAPPING.md   Where each spatial layer came from and how it was
                       prepared.

  TESTS_GUIDE.md       What the test suite covers, how to run it, and the rules
                       for writing one.


GENERATED -- DO NOT EDIT THESE
==============================

  FUNCTIONS.md         Every function called from more than one file: what it
                       does, what to pass it, what comes back. Built from the
                       roxygen block above each function. Edit the code, then
                       rerun the generator named at the top of the file.

  PACKAGES.md          Every R package the pipeline needs, grouped by what it is
                       for, and the command that installs them. Built from
                       BEESCABR_PACKAGES in config.R.

  BEE_THEMES_PALLETE.png  A reference sheet of the live colour tokens, redrawn
                       by scripts/analysis/render_palette.R whenever the theme
                       changes. Edit the theme, not the picture.
